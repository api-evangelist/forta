# Forta

> Forta is a decentralized, real-time detection network for monitoring the security and operational health of Web3 systems. Spun out of OpenZeppelin and backed by a16z crypto, thousands of community-built detection bots run on independent scan nodes that inspect every transaction and block across major EVM chains, emitting alerts that DeFi protocols and security teams subscribe to. Developers query alerts through a GraphQL API, build bots with the Forta Bot SDK/CLI, and the Forta Firewall product blocks smart-contract exploits before they execute.

## API

- [Forta GraphQL API](https://docs.forta.network/en/latest/api/): Single GraphQL endpoint at https://api.forta.network/graphql. POST queries with a Bearer API key. Primary query: `alerts`. Relay-style cursor pagination (pageInfo/endCursor/hasNextPage). Paid plan required.
